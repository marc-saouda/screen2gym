Environment Compiler

Turn a screen recording into a
trainable RL environment.

screen2gym takes a raw, action-labeled computer-use recording and compiles it into the two things an RL episode needs — what task the user performed and the initial state each episode resets to — then boots that seed into a live, resettable, automatically-graded multi-app environment.

What it is

Two halves: a compiler, and the environment it targets

The recording is hard to reason over directly (a 1-hour 1080p capture is ~300 MB / ~100k frames). screen2gym splits the work cleanly so the result is cheap to produce, reproducible, and inspectable.

rl_seed_pipeline The compiler

Reads the event stream + key-frames and emits a structured seed.json (task + initial_state) and an episodic curriculum.json. Deterministic stages do the heavy lifting offline; a single targeted vision-LLM call reads exact on-screen data.

rl_env The target environment

Boots the seed into simulated Google Sheets / Slack / Zapier apps that are fully resettable and gradeable, exposed through a standard Gymnasium API with a check-registry reward and an LLM success judge (with a deterministic fallback).

The seed in action

One recording → an episodic curriculum

The long session is sliced into small, independently-resettable sub-tasks. Each episode resets to the cumulative state at its start (via three knobs) and is graded by just its own checks — so a single sub-task is solvable on its own and a do-nothing policy scores below 1.0. Click an episode:

Why it's a good approach

Design decisions that pay off

🧮

Deterministic core, tiny VLM tip

The expensive reasoning (typed-text reconstruction, app/URL phases, key-frame selection) is deterministic and free. The model is used once, on a compact high-signal evidence pack — keeping cost low and the result reproducible.

🔁

Server-rendered dual-mode

Because the apps render from state on every request, a Playwright click and an HTTP POST hit identical logic. Grading is mode-independent, so training can run pixel-accurate or headless-fast with no divergence.

🧩

Resettable episodic curriculum

Each sub-task resets to its own cumulative state and is graded by only its checks. That makes credit assignment clean and lets an agent train on any single step independently.

🛡️

Graceful judge fallback

The fuzzy LLM judge always carries a deterministic substring/heuristic cross-check. If the network or key is unavailable the env still grades — it never hard-depends on an API.

🔍

Inspectable by construction

Every stage writes an artifact (evidence.json, seed.json, curriculum.json). You can read exactly what the model saw and why an episode is shaped the way it is.

🎛️

Standard Gymnasium surface

One gym.make("SaltStone/E<n>-v0") id per episode, dict observation, JSON/text action — drop-in for any RL library while the policy is typically an LLM.
